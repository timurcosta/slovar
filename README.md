# Охотники за ошибками

Пиксельная игра-тренажёр по русскому языку для младших школьников: побеждай боссов, вставляя
пропущенные буквы в словарных словах, собирай монеты и наряжай героя.

**Играть:** https://timurcosta.github.io/slovar/ (ведёт на игру в Yandex Cloud)

Ученик входит по коду от учителя, прогресс сохраняется у учителя и доступен с любого устройства.
Без интернета играть можно: прогресс отправится, когда сеть появится.

## Разработка

```bash
npm i
npx playwright install chromium
npm run dev      # http://localhost:5173
npm test         # модульные тесты
npm run check    # сборка и сценарии в браузере
```

Устройство кода, правила и формулы баланса — в [CLAUDE.md](CLAUDE.md).
