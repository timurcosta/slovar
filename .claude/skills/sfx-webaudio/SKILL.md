# Звук: синтез в WebAudio

## Инструменты (`apps/web/src/audio/`)

- `tone(f, d, type, vol, slide, delay)` в `sfx.js`: осциллятор с экспоненциальным затуханием.
  `f` частота Гц, `d` длительность с, `type` square/triangle/sine/sawtooth, `vol` 0.03–0.08,
  `slide` конечная частота (глиссандо), `delay` сдвиг старта. Уважает `settings.muted`.
- `noiseSweep(f0, f1, dur, vol, q)`: шум через полосовой фильтр, частота едет от `f0` к `f1`.
  Для свистов, ударов, шлепков.
- `sfx.*`: именованные эффекты. Вызываются из боя, магазина, наград. Новый эффект добавляй сюда,
  а не inline-вызовом `tone` в экране.
- `music.js`: `TRACKS`. Боевые («Дикий бой», «Полёт», «Пещера», «Дорога», «Пираты») — в
  `TRACK_ORDER`: новый бой берёт следующий (`nextBattleTrack`), кнопка «Музыка» листает вручную;
  «Чемпион» (`FINAL_TRACK`) — только у финальных боссов (`G.final`); спокойные («Спокойная», «Облака», «Городок», «Звёзды») играют вне боя по экрану
  (`SCREEN_MUSIC`, вызывается из `show()`). Стиль `gb` — под Game Boy: импульсы 12.5%/25% через
  `PeriodicWave`, волновой бас `bass`, второй голос `p2`, `soft` для тихих, `vol` — множитель громкости.
  `startMusic(id)` плавно меняет трек, `pauseMusic`/`resumeMusic` — пауза без забывания трека,
  `duckMusic(ms)` приглушает музыку на время громкого эффекта, темп +15% в ярости босса.
- `context.js`: `AudioContext` создаётся по первому касанию (`unlockAudio`), с тихим wav для iOS.
  Любой звук до касания молча не сыграет, это нормально.

## Характер звука по типу волны

| Волна    | Звучит как           | Берём для                              |
| -------- | -------------------- | -------------------------------------- |
| square   | 8-бит, ярко          | удары, монеты, фанфары, крит           |
| triangle | мягко, флейта        | лечение, добрые события, подложка      |
| sine     | глухо, бас           | удар о землю, «тяжесть», низ аккорда   |
| sawtooth | резко, жужжит        | лазер, огонь, ошибка, злые способности |
| шум      | свист, шлепок, взрыв | замах, падение, клякса, туман          |

## Рецепты (по образцу существующих)

- **Положительное короткое** (монета, попадание): 2 ноты вверх, square, 0.06–0.12 с, вторая с
  `delay` 0.06. См. `coin`, `hit`.
- **Победа, уровень**: арпеджио мажора вверх 4–6 нот с шагом 0.08–0.1 с (`win`, `level`).
  Частоты до-мажора: 262 294 330 349 392 440 494 523 659 784 1046.
- **Крит, комбо**: быстрое арпеджио 4 нот через 0.05 с, выше обычного (`crit`).
- **Урон герою, ошибка**: нисходящее глиссандо sawtooth 220 → 70 за 0.35 с (`hurt`), проигрыш —
  4 ноты вниз triangle (`lose`). Не делать громче 0.07: ребёнок ошибается часто, звук ошибки не
  должен раздражать и пугать.
- **Способность босса**: короткий «сигнал опасности» 0.2–0.4 с, своего тембра: туман — шум
  600 → 200 Гц, заморозка — высокий sine с глиссандо вниз, клякса — `thud`. Ребёнок должен по звуку
  понимать, что случилось, не глядя на экран.
- **Покупка, сундук**: `coin` + `fanfare(false)`; для редкой вещи `fanfare(true)`.

## Правила

- Громкость: эффекты 0.03–0.08, фанфары до 0.06 на голос. Суммарно несколько голосов легко уходят
  в клиппинг, проверяй в наушниках.
- Щелчки: гейн всегда уводи через `exponentialRampToValueAtTime` к 0.0001, не к 0, и не обрывай
  осциллятор раньше хвоста (`stop(t + d + 0.02)`).
- Длительность: эффект не длиннее действия на экране. Ответ сменяется за ~0.6 с, значит звук
  ответа до 0.3 с, фанфара за босса может быть 2 с.
- Музыка: трек это `bpm`, `roots` (midi-нота по тактам), `q` (мажор/минор), `mel` через `flatMel`
  (`[нота, длина в шестнадцатых]`), `kick`/`snare` шаги, `style` выбирает оркестровку в `musicStep`.
  Новый трек: добавь в `TRACKS` и в `TRACK_ORDER` (бой) или `SCREEN_MUSIC` (экраны).
  8 или 16 тактов по 16 шагов, мелодия должна возвращаться в тонику на последнем такте, иначе петля
  «спотыкается».
- Детям: без диссонансов и низкого гула, темп 88–140, мелодия в диапазоне 60–84 midi.
- Проверка: `scripts/check.mjs` не слышит звук, но ловит ошибки консоли (например, обращение к
  `ac` до разблокировки). Слушай руками через `npm run dev`, включая режим без касаний.

## Если нужен черновик вне кода

Для подбора тембра удобен внешний скилл `retro-audio` (sfxr-подобные параметры → WAV), но в игру
переносятся только параметры в `tone`/`noiseSweep`: файлы в проект не кладём.
