# Педагогика слов

Цель игры: ребёнок 7–10 лет запоминает написание словарных слов и приходит к репетитору с меньшим
числом ошибок. Любая механика проверяется вопросом «станет ли ошибок меньше через неделю».

## Что уже есть в коде

| Механика                       | Где                                                                                                                                   |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| статистика `{слово: WordStat}` | `state/stats.ts`, `stat(word, key, typed)`: `right`, `wrong`, `last`, `streak`, `typed`, `lastWrong` (новые поля необязательны)       |
| выучено / надёжно              | `isLearned`: серия верных подряд `>= LEARN_N` (без `streak` — по `right`); `isSolid`: ещё и вписано целиком (`content/rules.ts`)      |
| пул и очередь боя              | `poolFor`; `wordQueue` в `battle/round.js` → `buildQueue` (`topics/words/schedule.ts`): просроченные повторения, 3–5 новых, остальное |
| интервалы                      | `schedule.ts`: 1, 3, 7, 14, 30 дней по серии, ошибка → 1 день; `due`, `overdue`                                                       |
| ошибка возвращается в бою      | `requeueMiss`: через 3–6 вопросов (кроме заданий Ралины)                                                                              |
| работа над ошибками            | `errWords()` → `errorWords`: `wrong·2 > right` или последний ответ — ошибка; недавние выше; до 25                                     |
| новые слова                    | `newWords()`: ещё не встречались; тренировка берёт 20                                                                                 |
| ловушка в вариантах            | `autoWrong` в `topics/words/parse.ts`: типичная ошибка, а не случайная буква                                                          |
| вписать слово                  | `G.type`: ввод целиком, ×2 награда, экранная клавиатура                                                                               |
| режим ответа от репетитора     | `settings.answer`: pick / type / grow; «по росту» — `typeFor` (`content/rules.ts`): новое выбором, серия ≥ 2 — ввод, `missTyped`      |
| лимиты дня                     | `progress/limits.js`: минуты, новые слова, ответы, бои, ошибки                                                                        |
| трудные слова у репетитора     | `tutor/main.ts` `hardWords`, вкладка «Статистика» в разделе учителя                                                                   |
| журнал боёв и календарь        | `P.hist` (60 боёв: ответы, ошибки, выученные), `P.dlog` (итоги 180 дней); `progress/history.ts`, вкладка «История» в кабинете         |
| слова репетитора               | `settings.words === "custom"`, формат `м(о/а)локо`                                                                                    |

Чего пока нет: кабинет не показывает `isSolid`, давность и «ни разу не видел»; интервалы не учитывают
время на ответ.

## Принципы, на которые опираемся

1. **Вспоминание сильнее перечитывания.** Выбор буквы уже вспоминание, вписывание слова сильнее.
   Подсказка до ответа убивает эффект: показывать верную букву только после ответа.
2. **Ошибка исправляется сразу и видно.** После неверного ответа ребёнок должен увидеть всё слово с
   выделенной буквой и задержкой, достаточной для прочтения (не меньше 1.2 с), а в бою это ещё и
   момент «босс ударил», поэтому слово не должно исчезать в анимации.
3. **Ошибка возвращается.** Слово с ошибкой должно попасться снова в этом же бою (через 3–6 вопросов),
   а не только в тренировке ошибок (`requeueMiss`).
4. **Интервалы.** Повторять через 1, 3, 7, 14, 30 дней после верных ответов, ошибка сбрасывает на 1 день
   (`schedule.ts`). У старых записей без `last` повторение считается просроченным, сначала с ошибками.
5. **Чередование.** Смешивать темы и классы (`ab`) лучше для запоминания, но труднее. Для 1–2 класса
   держи «a», для уверенных «ab». Не делать бой из 20 слов на одну орфограмму подряд.
6. **Порция.** 3–5 новых слов за бой, остальное повторение. Лимит «новые слова в день» для этого
   и существует, уважай его в тренировке новых слов.
7. **Ловушка должна быть правдоподобной.** `autoWrong` даёт `о↔а`, `е↔и`: это ошибки, которые дети
   реально делают. Не подставляй случайные буквы, ребёнок не учится на них.
8. **Не наказывать за ошибку учёбой.** Ошибка = урон по герою, не «штрафные 10 слов». Тон текста:
   «Запомни: м**о**локо», а не «неправильно».

## Что показывать репетитору

Полезно: список трудных слов по убыванию ошибок (есть), сколько слов выучено (есть), когда
ученик играл последний раз, какие слова он ни разу не видел (можно из `newWords`), сколько раз вписывал
целиком. Бесполезно: монеты, уровень героя, предметы (ребёнок сам расскажет).
Данные детей минимальны: только имя, прогресс, статистика слов.

## Проверка

- Логику выбора слов покрывай тестами в `apps/web/test/` (чистые функции в `pools.js` с подменённой
  `stats`), не только скриншотами.
- Сценарий `new` в `scripts/check.mjs` отвечает на вопросы: добавь шаг с ошибкой, если меняешь то,
  что видно после неверного ответа, и посмотри `new-07-after-answer`.
- Тексты для детей согласуй со скиллом `kid-cool`: полезно, но должно оставаться игрой.
