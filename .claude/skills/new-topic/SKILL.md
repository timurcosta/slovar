# Новая тема

Игра задумана как одна игра с несколькими темами, а не набор игр. Боссы, награды, гардероб,
прогресс и статистика общие. Тема это только «откуда берутся вопросы».

## Сначала проверь, ложится ли тема в формат слов

Вопрос сейчас: `WordEntry` из `topics/words/parse.ts`: слово с местами выбора
`б(е/и)рёза`, несколько мест в слове допустимы, ловушка подбирается `autoWrong`, если не указана.
В бою спрашивается одно место (кнопки «е» / «и»), в режиме «вписать» всё слово.

Ложится без правок боя, если задание сводится к «выбери из двух вариантов в этом месте»:

- парные согласные: `ду(б/п)`, мягкий знак: `кон(ь/)` (пустой вариант пока не поддержан, проверь `parse.ts`);
- ударение: `зв(о́/о)нит`, если решим показывать ударную букву;
- приставки/предлоги: `(в/во)шёл` работает, если варианты разной длины допускает `parseEntry`.

Тогда тема = новая папка `topics/<тема>/` со списками и `parseList`, плюс пункт выбора в настройках
учителя (`ui/screens/teacher.js`, `settings.words`) и в кабинете (`tutor/main.ts`). Пулы в
`topics/words/pools.js` (`poolFor`, `errWords`, `newWords`) завязаны на `settings.words`: расширь
их так, чтобы статистика `stats` различала темы (сейчас ключ статистики это слово, одинаковое слово
в двух темах будет считаться одним).

## Если не ложится

Примеры: выбрать из 3–4 вариантов, ответ числом, пара «слово ↔ перевод», порядок слов.
Тогда сначала расширяй модель вопроса, не ломая словарные слова:

1. `battle/round.js`: `nextQ` строит `G.cur = { e, slot, opts }`, `resolve(ok, timeout)` засчитывает.
   Введи поле вида вопроса в `G.cur` и ветку рендера; две кнопки `opt0`/`opt1` в `index.html` станут
   списком.
2. Режим «вписать» (`G.type`, `renderTyped`) и экранная клавиатура должны либо работать с новым
   видом, либо честно отключаться для него.
3. Способности боссов работают с DOM слова (`#word`, `#opts`): туман, клякса, переворот должны
   не ломаться на новом рендере. Прогони бой с боссом с 3+ способностями.
4. Статистика `stat(word, "right"|"wrong")`, трудные слова в кабинете и задания дня (`quest("typed")`)
   опираются на слово как ключ: реши, что считать «словом» в новой теме.
5. Тесты: `apps/web/test/words.test.js` держит снимок списков, добавь аналогичный для темы.

## Общее для любой темы

- Тексты для детей по-русски, дружелюбно, с именем `P.name`. Ошибка показывает верный ответ.
- Репетитор задаёт тему и слова в кабинете; ученик получает настройки при запуске (`net/sync.ts`).
  Новая настройка это поле в `packages/shared/src/api.ts` и в `settings.ts`, оба конца.
- Цифры наград не трогай: множитель сложности (`diffMul`) задаётся режимом слов, тема сама по себе
  не должна платить больше. Если очень хочется, это `balance-change`.
- Перед тем как делать, прогони идею через `kid-cool`: тема должна быть похожа на бой, а не на тест.
