# Правка баланса

В игре реальный прогресс детей, а репетитор ориентируется на скорость накопления монет. Цифра,
поменянная «между делом», либо обесценит чьи-то 3 недели игры, либо сделает вещи недостижимыми.
Поэтому порядок строгий: сначала отчёт, потом правка, потом снимок.

## Где лежат цифры

| Что                              | Файл                                                                      |
| -------------------------------- | ------------------------------------------------------------------------- |
| уровни `lvlXP`, `MAXL`, титулы   | `apps/web/src/progress/levels.ts`                                         |
| монеты, опыт, сундуки            | `apps/web/src/progress/rewards.js` (`addCoins`, `addXP`, `grantChest`)    |
| награда за босса, башню          | `apps/web/src/battle/run.js` (конец боя, около `addCoins(`)               |
| ответ: урон, крит, сердца        | `apps/web/src/battle/round.js` (`resolve`), `progress/gear.js`            |
| множители сложности              | `apps/web/src/battle/difficulty.js` (`DIFF_MUL`, `DIFF_BOSS`)             |
| боссы кампании и башни           | `apps/web/src/content/bosses.js` (`BOSSES`, `towerBoss`)                  |
| цены, бонусы, редкость, прокачка | `apps/web/src/content/items.js` (`ITEMS`, `RARITY`, `UPGRADES`, `upCost`) |
| задания дня, вход подряд         | `apps/web/src/progress/daily.js`                                          |
| лимиты дня                       | `apps/web/src/progress/limits.js`                                         |
| выучено после N верных           | `apps/web/src/content/rules.ts` (`LEARN_N`)                               |

Формулы и ориентиры сведены в разделе «Экономика и баланс» CLAUDE.md. Сверяйся с ним, а не с памятью.

## Порядок работы

1. **Отчёт до правки.** Напиши пользователю коротко:
   - что было и что станет (формула или число);
   - для какого игрока заметно: новичок (1–3 босс, карандаш), середина (10–20 уровень, башня открыта
     после 6-го босса), ветеран (башня 15+, эпики);
   - как меняется ориентир «15 минут в день ≈ 150–250 монет» и за сколько дней покупается ближайшая
     цель этого игрока (цену дели на дневной доход).
     Если задача пришла без слова про баланс (например, «добавь босса в середину»), всё равно скажи,
     что цифры сдвинутся, и предложи вариант без сдвига (добавить в конец).
2. **Правь минимально.** Одна причина, одна цифра. Не «заодно округлю соседние».
3. **Снимки.** `npm test -w @repetitor/web`: упавший `balance.test.js` подтверждает, что изменение
   видно. Обнови `npx vitest -u -w @repetitor/web` только если изменение задумано, и назови в ответе,
   какой именно снимок обновлён. Падение `profile.test.js` или `migrations.test.ts` означает, что
   задета структура сохранений, это уже не баланс, остановись и разберись.
4. **Прогон.** `npm run check` и скриншоты экранов с цифрами (`veteran-02-shop`, `new-07-after-answer`,
   `veteran-08-tower-fight`, `veteran-04-awards`).
5. **Прогресс не должен падать.** Новая формула опыта требует новой версии `xpv` с подъёмом `xp`
   (см. `state/migrations.ts`). Подорожавшая вещь, которую кто-то уже носит, остаётся у него.
   Подешевевшая не возвращает разницу, и это нормально, но скажи об этом.

## Что считается балансом, а что нет

Баланс: любая цифра из таблицы выше, множители, шансы, пороги способностей (с какого этажа), число
заданий. Не баланс: тексты, цвета, порядок вкладок, анимации, исправление явного бага в формуле
(например, множитель применяется дважды). Исправление бага всё равно меняет цифры, поэтому отчёт
«было → станет» нужен и для него.

## Быстрые оценки

- Доход за бой: ~12–20 верных ответов × 3 монеты × множители + награда за босса `30 + idx·9` + сундук.
  На лёгких словах множитель 1, на сложных 2.
- Сундук t: среднее `25 + 18t + (25 + 18t)/2`, то есть t=1 ≈ 65, t=3 ≈ 120.
- Цена прокачки растёт как `base · k^n`: проверь, что десятый уровень не стоит дороже мифа.
- Лестница редкости по цене: обычный < 400 < редкий < 1500 < эпик < 5000 < легенда < 15000 < миф.
  Новая вещь должна попасть в свою ступень и по цене, и по силе.
