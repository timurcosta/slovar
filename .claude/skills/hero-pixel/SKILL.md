# Пиксели: герой, боссы, питомцы

Всё рисуется кодом на маленький canvas, CSS растягивает с `image-rendering: pixelated`.
Файлов с картинками нет, поэтому «нарисовать» значит написать пиксели в JS. Ниже две системы:
герой (процедурно, `render/hero.js`) и строковые спрайты (боссы, питомцы, предметы, `content/sprites.js`).

## 1. Герой: `drawHero(cv, eq, wrap, fr)` в `apps/web/src/render/hero.js`

Размеры заданы в начале функции и повторены в CLAUDE.md. Главное, что нужно держать в голове:

| Что                | Значение                                                                |
| ------------------ | ----------------------------------------------------------------------- |
| фигура             | `W=30 × H=27`, тело начинается с `ox=6, oy=4`                           |
| запас сверху       | `TOP=4` (поднятое оружие, дыхание `breathe`)                            |
| полоса под питомца | `PETW=10` слева, питомец рисуется в `x - 10`                            |
| холст              | `CW=42 × CH=32`, по краям 1px под обводку                               |
| ось зеркала        | `x = ox + 10 = 16` (локальные координаты)                               |
| кадр анимации `fr` | тикает каждые 170 мс: крылья `fr/2`, дыхание `fr/4`, моргание `fr % 17` |

Помощники внутри функции:

- `R(x, y, w, h, цвет)` прямоугольник, `P(x, y, цвет)` пиксель.
- `M(x, y, w, h, цвет)` зеркальная пара относительно оси 16. Рисуй левую половину, правая получится сама. Если деталь несимметрична (меч в одной руке), используй `R`.
- `outlined(fn, цвет)` рисует группу на отдельном слое и обводит тёмным контуром 1px. Так делаются броня, шлем, оружие, чтобы они читались на любом костюме. В конце вся фигура обводится ещё раз.

Порядок слоёв в функции (снизу вверх): спина (плащ, крылья) → голова и тело → общая тень → детали
костюма → броня → шлем → оружие → питомец → контур фигуры → аура. Новую вещь вставляй в свой слой,
а не в конец: иначе шлем окажется поверх ауры или оружие под плащом.

Цвета костюма берутся из `COSTUMES[ck]` и переопределяются внешностью игрока (`look`: волосы, кожа,
глаза). Для тёмной кожи глаза и рот подменяются, чтобы не пропадали. Новый костюм обязан выглядеть
нормально со всеми вариантами кожи и волос: проверь `look` вкладку в магазине на скриншоте.

### Правила рисунка

- Силуэт важнее деталей: на телефоне фигура 30 px превращается в 90–120 px. Деталь в 1 px видна, но
  только если контрастирует. Светлая верхняя грань и тёмная нижняя у каждой «пластины» дают объём
  (так сделана броня, посмотри блок `armor`).
- Волосы: светлая верхняя строка, тёмная нижняя, чтобы не сливались с лицом.
- Не обрезай: если вещь не влезает, увеличь `TOP` или `PETW`, а не урезай рисунок. Все пять мест,
  где рисуется герой, растянут холст одинаково, поэтому смещение безопасно.
- Контрастность: палитра тёмная (`#141a33` фон обводки), поэтому вещи цвета `#2x2x3x` исчезнут.
  Проверяй на фоне главной (тёмный) и магазина.

### Где герой виден (проверь все)

`ui/screens/home.js` (главная), `battle/run.js` и `battle/effects.js` (бой, атака, замах без
оружия, питомец отдельно), `ui/screens/shop.js` (примерка, иконки предметов через `ic-<id>`, вкладка
внешности), `ui/screens/intro.js` (история), `progress/rewards.js` (подарок, сундук). Иконка предмета в
магазине рисует героя с одной подменённой вещью, значит вещь должна быть узнаваема и без остального.

## 2. Строковые спрайты: боссы, предметы, питомцы

`content/sprites.js`: `SPR[ключ]` строка, где `.` пусто, буква = цвет из `PALS[ключ палитры]`.
Строки одинаковой длины, обрезка и отступы делаются `drawSprite` (`render/sprite.js`).

- `BLINK[палитра]` = `{буква: буква}`: при моргании цвет первой подменяется второй (глаза закрываются
  цветом кожи). При ярости `drawBoss` красит те же буквы в красный (`#ff2a2a`, у Двойки жёлтый).
  Без записи в `BLINK` босс не моргает и не злится лицом.
- Один спрайт может иметь несколько палитр (робот `robot` и `cyber`): цветовая вариация дешевле новой
  фигуры, башня так же перекрашивает боссов CSS-фильтром `TOWER_FILTER`.
- Питомцы (`content/pets.js`): два кадра `PET_SPR` и `PET_SPR2` (моргание, хвост, крылья), палитра
  `PET_PAL`, тюбетейка `PET_CAP`. Ширина питомца не больше 10–12 px: он стоит в полосе `PETW` и на
  нижней линии `H`.
- Размер боссов 16–24 px по ширине. Лицо должно читаться на 1/4 экрана телефона: большие глаза,
  рот, один яркий акцент.

### Предпросмотр без сборки

```bash
node .claude/skills/hero-pixel/scripts/preview-sprite.mjs angelika            # босс, палитра по ключу
node .claude/skills/hero-pixel/scripts/preview-sprite.mjs robot cyber         # спрайт + другая палитра
node .claude/skills/hero-pixel/scripts/preview-sprite.mjs pet:cat             # питомец, оба кадра
node .claude/skills/hero-pixel/scripts/preview-sprite.mjs angelika --blink    # как моргает
node .claude/skills/hero-pixel/scripts/preview-sprite.mjs angelika --angry    # ярость
```

Скрипт пишет PNG в `.claude/skills/hero-pixel/out/` (в `.gitignore`), увеличенный в 8 раз. Открой
через Read и смотри. Героя так не посмотреть: `drawHero` зависит от DOM и профиля, его смотрим
через скриншоты.

## 3. Обязательная проверка

1. `npm run check`, затем открыть через Read скриншоты всех затронутых экранов из `shots/`:
   герой на `new-03-home`, `veteran-01-home`, `veteran-02-shop`, `veteran-03-shop-*`,
   `veteran-08-tower-fight`, `new-07-after-answer`; боссы на `new-05-intro`, `new-06-question`.
2. Новая вещь или костюм должны попасть на скриншот. Если «прокачанный» профиль в
   `scripts/check.mjs` их не носит, добавь в экипировку профиля `veteran` или добавь шаг
   с примеркой: иначе регрессию никто не заметит.
3. Скрипт падает при ошибках в консоли. Пустая иконка в магазине обычно значит, что `ITEM[id]`
   не найден или вещь не в своём слоте.

Если правишь только рисунок (без поведения), сравни скриншоты с базой побайтно, как описано в CLAUDE.md,
и убедись, что изменились только те файлы, которые должны были.
