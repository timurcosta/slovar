# Репетитор: «Словарная битва»

Браузерная пиксельная игра-тренажёр по русскому языку для младших школьников. Ребёнок бьёт боссов,
выбирая или вписывая пропущенную букву в словарном слове; за ответы получает монеты и опыт и тратит
их в гардеробе. Сейчас тема одна — словарные слова 1–4 класса. Игру планируется расширять **внутри
неё же** другими темами и механиками (например, запятые), а не делать отдельные игры.

- Прод: https://timurcosta.github.io/slovar/ (репо `timurcosta/slovar`, публичный — никаких секретов в коде).
- Деплой: `git push` в `main`, GitHub Pages обновляется сам за минуту-две. Сборки нет.
- Отвечай и пиши тексты в игре по-русски. Коммиты — короткие, по-русски, по смыслу изменения
  («Броня: полноценные доспехи поверх костюма»).

## Как запустить и проверить

```bash
open index.html             # работает прямо с диска (file://)
npm run serve               # или http://localhost:8000

npm i && npx playwright install chromium   # один раз
npm run check               # сценарии в Chromium, скриншоты и localStorage в shots/
```

`scripts/check.mjs` проходит три сценария: новый игрок (имя → история → главная → магазин → бой),
«прокачанный» профиль (все экраны, гардероб по вкладкам, башня) и старое сохранение (миграции).
Время и `Math.random` зафиксированы, поэтому прогоны **детерминированы** и их можно сравнивать побайтно.
Скрипт падает, если в консоли страницы есть ошибки.

После любой правки: `npm run check`, затем посмотреть скриншоты затронутых экранов (их можно
открывать через Read). Для рефакторинга без изменения поведения сравни с прошлой версией:

```bash
git worktree add /tmp/base HEAD
node scripts/check.mjs /tmp/base/index.html /tmp/shots-base
node scripts/check.mjs index.html /tmp/shots-new
for f in /tmp/shots-base/*; do cmp -s "$f" "/tmp/shots-new/$(basename $f)" || echo "DIFF $(basename $f)"; done
git worktree remove /tmp/base
```

Если меняешь вёрстку или рисунок героя — добавь шаг в сценарий, чтобы новое состояние попало в скриншоты.

## Устройство кода

Без фреймворков и сборки. `index.html` — только разметка экранов (`<section id="s-...">`),
стили в `css/style.css`, логика в `js/`.

### Главное правило про порядок файлов

Скрипты **обычные, не ES-модули** (модули не работают с `file://`). Все `const`/`let`/`function`
верхнего уровня лежат в одной общей глобальной области, файлы грузятся строго в порядке
`<script>` в `index.html`. Отсюда:

- код, который **выполняется сразу при загрузке** файла, может вызывать только то, что объявлено
  в этом файле или раньше. Подъём `function` работает только внутри одного файла;
- внутри функций и обработчиков можно ссылаться на что угодно — к моменту вызова всё загружено;
- новый файл добавляй в `index.html` в правильное место списка;
- не называй глобальные переменные именами, занятыми `window` (`top`, `location`, `name`, `status`…).

После перестановок проверь, что в консоли нет `ReferenceError` (это ловит `npm run check`).

### Состояние

- `P` — профиль игрока (сохраняется целиком), `G` — текущий забег (`null` вне боя), `settings`,
  `stats` — `{слово: {right, wrong}}`.
- Любое изменение `P` → `save()`. Экраны перерисовываются явно (`renderHome()`, `renderShop()`, `renderHUD()`).

## Формат слов и новые темы

Слово записывается с вариантами в скобках: `б(е/и)рёза` — верно `е`, ловушка `и`. Если ловушка не
указана, её подбирает `autoWrong` (`о↔а`, `е↔и`, удвоенная → одинарная: `а(лл)ея`, заглавная →
строчная). В слове может быть несколько мест; в бою спрашивается одно, в режиме «вписать» — всё слово.
Учитель может задать свои слова тем же форматом (`settings.words === "custom"`).

Новая тема (например, запятые) должна стать ещё одним источником вопросов, а не отдельной игрой:
свой файл в `js/data/`, выбор темы рядом с выбором слов, а боссы, награды, гардероб и прогресс — общие.
Вопрос сейчас — это «слово с местами для выбора» (`{segs, slots, word}`), и сам формат уже подходит
для многих тем. Если тема не ложится в него, сначала расширь модель вопроса в `game.js`
(`nextQ`/`resolve`), не ломая словарные слова.

## drawHero: размеры холста

`drawHero(cv, eq, wrap, fr)` рисует героя попиксельно на маленький canvas, а CSS растягивает его
(`image-rendering: pixelated`). Размеры заданы в начале функции:

- фигура `W=30 × H=27`, сверху запас `TOP=4` (поднятое оружие, «дыхание»), слева полоса `PETW=10` под питомца;
- холст `CW = W+2+PETW = 42`, `CH = H+1+TOP = 32`; по краям 1px запаса, чтобы не резался контур;
- рисование идёт в локальных координатах со сдвигом `(LX=11, TOP)`; тело героя от `ox=6, oy=4`;
- `M(...)` рисует зеркальную пару относительно оси `x = ox+10`; `R` — прямоугольник, `P` — пиксель;
- питомец рисуется левее, `x - 10`, и стоит на нижней линии `H`; ауры — в координатах 0..29 × 0..26;
- `outlined(fn)` обводит группу пикселей тёмным контуром, в конце обводится вся фигура;
- `fr` — номер кадра анимации (крылья, дыхание, моргание, ауры, питомцы), тикает каждые 170 мс.

Если что-то не помещается — увеличивай запасы `TOP`/`PETW`, не обрезай. Один и тот же `drawHero`
рисует героя на главной, в бою, в магазине (примерка), на экране конца и в подарках, проверяй все места.

## Профиль и миграции (осторожно)

Ключи localStorage: `sb2_profile` (профиль `P`), `sb_settings`, `sb_stats`, `sb_custom`, `sb_pin`
(хэш PIN учителя); `sb_hero` — самый старый формат, переносится при первом запуске.
У детей реальный прогресс, потерять его нельзя.

- `P = Object.assign(freshProfile(), сохранённое)` — слияние **поверхностное**. Новое поле верхнего
  уровня добавляй в `freshProfile()`. Вложенные объекты (`tot`, `up`, `equip`) доливаются отдельно
  ниже — новое вложенное поле добавляй и туда.
- Предметы хранятся по `id` в `P.owned` и `P.equip`. **Не переименовывай и не удаляй id.** Если
  нужно убрать предмет — пиши миграцию с компенсацией (как `oscar` → `cat` + 2500 монет).
  Экипировка с неизвестным id сбрасывается на `DEFAULT_EQUIP` раньше остальных миграций.
- `P.beaten` и `P.unlocked` — **индексы** в `BOSSES`. Вставка босса в середину `CAMPAIGN` сдвигает
  индексы: нужна миграция по именам и новая версия `rv` (см. блок `rv` в `profile.js`). Добавлять
  в конец безопаснее.
- Смена формулы опыта — новая версия `xpv` с подъёмом `xp`, чтобы уровень игрока не упал.
- Код сохранения (`SBZ…`/`SBJ…`) — это сжатый JSON `{v, p: P, s: stats}`. Старые коды после
  загрузки проходят те же миграции, поэтому миграции не удаляй.
- Сценарий `legacy` в `scripts/check.mjs` проверяет миграции; при новой миграции дополни его.

## Экономика и баланс

**Не меняй баланс без явной просьбы.** Если правка задевает цифры (цены, награды, урон, жизни
боссов, уровни), сначала напиши, что было и что станет, и для какого игрока это заметно.
Ориентир: 15 минут игры в день дают примерно 150–250 монет.

- Уровни: `lvlXP(n) = 50·n·(n−1) + n³`, максимум 50. За уровень: `60·l` монет + сундук 1 уровня без вещи.
- Верный ответ: монеты `(крит ? 6 : 3) · mult`, опыт `(крит ? 15 : 10) · mult`,
  `mult = (вписать слово ? 2 : 1) · diffMul`, `diffMul`: смешанные слова 1.5, сложные 2, иначе 1.
- `addCoins` умножает на `gear().coinMul` (броня, питомец, «Богатство» +10% за уровень), если не
  передан `useMul=false`; `addXP` умножает на `gear().xpMul` (шлем).
- Победа над боссом: монеты `30 + idx·9` (в башне `30 + этаж·9`), опыт `30 + idx·5` (башня `30 + этаж·4`),
  оба × `diffMul`; плюс сундук. Каждый 10-й этаж башни: `300 + этаж·20`.
- Сундук уровня t: `25 + 18t + rand(25 + 18t)` монет; шанс вещи `0.08 + 0.04t` (только вещи дешевле 1500,
  открытые по уровню).
- Задания дня: 3 штуки, награда `90 + 45·i` за сложность i; все три — сундук 3 уровня.
  Вход подряд: `30 · min(дней, 7)`.
- Боссы кампании: жизни `90 + 20·i`, время `max(5, 13 − 0.35·i)` с. Башня: жизни `110 + 22f + 0.35f²`,
  время `max(4.5, 12 − 0.3f)`, способности добавляются с 3, 6 и 15 этажа.
  Сложность: смешанные ×1.3 жизни, ×0.8 времени, +1 способность; сложные ×1.7, ×0.62, +2.
- Бой: урон оружия + питомец + «Сила»; вписанное слово ×1.5; крит с серии 3 (×2, у некоторых питомцев
  больше); каждые 5 подряд +1 сердце. Сердца `5 + броня + «Живучесть» (+2 на лёгких словах) + лепёшка`.
- Прокачка: цена `base · k^n`, округление до 10. Лестница редкости по цене: обычный < 400,
  редкий < 1500, эпик < 5000, легенда < 15000, миф < 40000, ультра от 40000.

## Прочее

- Раздел учителя закрыт PIN (хранится хэш). Там же лимиты на день (минуты, новые слова, ответы,
  бои, ошибки): при достижении бой останавливается, прогресс сохраняется.
- Музыка и звуки синтезируются в WebAudio, внешних файлов нет. Шрифты — Google Fonts.
- Тексты для детей: дружелюбно, без пугающих формулировок, обращение по имени (`P.name`).
- Учитывай телефоны: проверки идут в окне 390×844, есть сенсорный режим (`TOUCH`) и экранная клавиатура.
